Dealership Accelerator · Internal Tool · UI Design

KPI Tracker UI Design

Static design reference for the KPI Tracker screens, built on the DAOS Design System (jet black, Sea Salt text, DA Lime for emphasis only, Inter, 8pt grid). Covers the three CRUD surfaces: KPIs, Views (grouping KPIs), and access to Views. Status uses semantic green / yellow / red, always paired with a label. Never color alone. These are mockups, not the live app.
